# 별숲마을 여행 안내 사이트

## 목적
별숲마을을 소개해 별 보러 오고 싶게 만듭니다.

## 사용자
주말 힐링 여행지를 찾는 사람, 휴대폰으로 보는 사람

## 핵심 기능
- 마을 명소 소개
- 마을 먹거리 소개
- 누르면 펼쳐지는 질문

## 화면 구성
위: 메뉴 / 가운데: 큰 그림과 소개 / 아래: 연락처

## 하지 않을 것
로그인, 예약, 결제, 방명록

## 마을 설정 (모든 내용은 가상으로 만들어 주세요)
- 이름: 별숲마을 (산속 작은 마을, 해발 700m)
- 특산물: 산나물, 야생화 꿀
- 축제: 별숲 별빛축제 (9월 25~27일)
- 분위기: 고요하고 포근함

## 메뉴
- 모든 페이지 위에 같은 메뉴 (7개 페이지 링크)
- 휴대폰에서는 메뉴를 버튼으로 접기

## 형태
- 페이지마다 HTML 파일 하나
- CSS와 JS는 HTML 안에
- **이미지 파일은 쓰지 않음** (그림은 모두 SVG, CSS 그라디언트, 이모지로 표현)

## 페이지 목록과 내용
- index.html (홈): 별이 가득한 밤하늘 그림, 한 줄 소개, 명소·먹거리·축제로 가는 카드 3개
- about.html (마을 소개): 마을 이야기, 기본 정보 6개(위치·인구 등, 가상), 마을 풍경
- spots.html (명소): 명소 카드 4개 (그림, 이름, 한 줄 설명, 주소)
- food.html (먹거리): 특산물 음식 카드 4개 (그림, 이름, 식당, 주소, 가격)
- festival.html (축제): 축제 소개, 일정표, 대표 프로그램 3개
- map.html (오시는 길): 간단한 약도 그림(SVG), 버스·자동차로 오는 법
- faq.html (자주 묻는 질문): 질문 5개, 누르면 답이 펼쳐짐

## 링크
- 모든 페이지 위 메뉴: 7개 페이지로 가는 링크
- 지금 보고 있는 페이지는 메뉴에서 색으로 표시
- 마을 이름(로고)을 누르면 홈(index.html)으로
- 홈의 카드 3개는 spots.html, food.html, festival.html로 연결

## 그림
- 사진 대신 SVG와 CSS로 직접 그리기 (밤하늘, 달, 산, 전나무 숲, 불 켜진 오두막)
- 모든 그림은 같은 색감(남색 밤하늘, 달빛 노랑)으로
- 카드 그림은 그라디언트 배경 위에 큰 이모지

## 해솔마을과 다른 점
- 색: 파란 바다·노을빛 → 남색 밤하늘·달빛 노랑
- 이미지 파일 없음 (해솔마을은 images 폴더의 PNG 사용)
- 페이지 7개 (해솔마을은 10개: 추천 코스·숙소·갤러리 없음)
