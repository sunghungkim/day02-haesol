## 📁 구성

```
index.html ... faq.html   해솔마을 10개 페이지 (사진은 images/ 폴더)
images/                   해솔마을 사진 16장
byeolsup/                 별숲마을 7개 페이지 (이미지 없이 SVG·CSS로 그림)
dahyang/                  다향마을 7개 페이지 (이미지 없이 SVG·CSS로 그림)
```

- 각 마을 폴더에 요구사항 문서(PRD)가 있습니다. 별숲마을과 다향마을은 `PRD.md`, 해솔마을은 `2일차-해솔마을 PRD템플릿.txt`입니다.
- 모든 페이지는 HTML 한 파일에 CSS와 JS가 함께 들어 있는 독립된 파일입니다.

> 이 사이트의 마을, 주소, 가격, 일정, 연락처는 모두 **가상으로 만든 정보**입니다.
